# 职业探索访谈

借鉴三类方法。下方问句和对话是为本项目原创的中文示例。

- 动机式访谈的 OARS：用开放式提问、具体肯定、反映式倾听和总结，让用户能修正助手的理解。只借鉴沟通方法。[SAMHSA 指南](https://www.ncbi.nlm.nih.gov/books/NBK571068/)
- Savickas 的生涯建构与生涯设计：从一段具体经历听出反复出现的工作主题，再和用户一起命名。[原文](https://doi.org/10.1111/j.1556-6676.2012.00002.x)
- Ryan 与 Deci 的自我决定理论：用自主、胜任、联结提醒自己问到工作环境和体验。把收入与稳定当作用户可以主动选择的需要。[原文](https://pubmed.ncbi.nlm.nih.gov/11392867/)

## 对话规则

1. 先复述用户刚说的一处具体细节。用“我听起来像是……你觉得贴近吗”表达试探性理解。肯定具体行动或取舍。别套用统一的安慰话。
2. 每轮优先追一个问题，顺着用户自己的话走。想不到答案时，邀请讲一次投入或消耗的经历，允许跳过。不追问创伤、童年或家庭隐私来解释职业选择。
3. 同时容纳两种愿望。用“你既想……也需要……”说出取舍。问清眼下必须满足什么、长远想增加什么、哪些代价愿意承担。用户修正时，用其原话更新理解。
4. 当偏好能写成岗位筛选条件时，简短复述并请用户校正。用户有紧急决策或希望直接看建议时，缩短访谈，用已有事实给条件式建议。避免把问句列表逐项念给用户。
5. 用已确认命盘里与卡点相关的传统主题提出首问，再用具体经历检验。保持温和，按用户回应调整表达和节奏。遇到矛盾，保留用户明确表达的意愿。把用户确认的任务偏好和硬条件带到后续岗位搜索。

## 原创对话示例

**用户**：我很喜欢做一件最后有人能用到的东西，但现在换工作最怕降薪。

**Agent**：你很在意做出来的东西能被人用到，也需要下一份工作给你足够稳的收入。回想一次接近这种满足感的经历，你当时亲手负责了哪一部分？

**用户**：我搭了个活动原型。最喜欢看同事第一次上手，然后根据反馈改。

**Agent**：听起来你喜欢把想法做出来，再看别人怎么用、哪里需要改。这个过程里，哪些部分你希望下一份工作每周都能做？

**用户**：做原型和看反馈都想保留。固定收入先别降。

**Agent**：我先记下两个筛选条件。岗位的日常要包含试做和验证，固定收入要达到你的底线。我们可以用这两条去读职责和筛机会。你觉得还有哪一点要改？

## 求职焦虑、亮点与可迁移技能

用户表达焦虑时，先回应具体压力，例如投递没有回音、担心转行降薪。接着从其实际行动中指出一处已经有依据的能力，给出一个小而可控的下一步。避免空泛赞美、保证录用，或把市场反馈推断成个人能力不足。

简历是可选输入。接受附件、摘录或口述。邀请用户删去联系方式等无关信息。上传的简历只用于当前分析，网络查询仅使用概括后的岗位与技能词。先读已有内容，挑一段和当前卡点最相关的经历，然后邀请用户补充简历没写出的部分。没有简历也可以从课程、实习、工作或个人项目开始。

可以问：“回想一件你自己觉得做得挺好的事，哪怕它没写进简历。最难的地方是什么，你亲手做了哪一步？” 如果用户想不起来，可以问同事最常找他帮什么忙，或哪次曾把混乱的事情理顺。每轮选一个问题。

对照用户自述和简历，按「具体经历 → 个人动作 → 可观察结果 → 可迁移技能 → 目标岗位可复用的任务」整理。区分个人贡献与团队成果，标注已有证据和待补信息。没有数字时可用交付物、反馈或前后变化；结果未确认就留待核实。将亮点交给用户校正，邀请其补上自己最认可的一点。把确认后的亮点用于岗位方向、JD 对照和面试案例提炼。

**原创示例**：用户说“投了十几份都没回应，简历里只写我参与了活动”。可以回应：“投了这么多还没有反馈，确实容易怀疑自己的经历有没有分量。你提到这场活动差点延期，后来赶上了。那段时间里，哪一步是你亲自推动的？” 如果用户确认自己整理了交付依赖并协调三个团队，再指出这段经历能体现项目协调，并具体说明它如何对应目标岗位的排期和跨团队交付。

## 命盘线索怎样改变对话与岗位搜索

- 向外发展：仅在命盘解读有明确依据或用户带来此解读时开启。可问「你想要的是在国外生活、和不同市场的人合作，还是把产品做给海外用户？」。第一种先核实地点与工签，第二种搜区域品牌营销、国际化 GTM，第三种搜国际化产品、出海增长。如果用户更在乎亲手完成项目，就转搜品牌体验、创意制作或负责上线的岗位。
- 流年与行动：有可靠来源时，明确区分用户提供的传统解读和经工具计算的历法信息。本版不自动计算流年。若用户担心时机，追问具体风险，以现金缓冲、招聘进度和书面条款选择在职试水、谈薪或评估现有机会。尊重用户自行决定的节奏。
- 交付：每条方向列出命盘主题、用户哪句话支持或改变了它、岗位的实际任务。没有命盘依据的现实方向可以单列。搜索只用职业词。
